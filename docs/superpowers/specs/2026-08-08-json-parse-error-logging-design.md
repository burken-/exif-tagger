# Design Document: JSON Parse Error Logging & Encoding Robustness in `ai_client.py`

## Overview
When the AI model returns JSON, parsing can fail due to invalid JSON syntax, unescaped control characters in LLM output, or encoding edge cases (e.g. byte inputs, BOM prefixes). This design adds comprehensive error logging in `_parse_response` when `json.loads` fails, while also adding defensive encoding/parsing handling (`bytes` decoding, BOM stripping, and `strict=False` in `json.loads`).

## Requirements & Goals
1. **Encoding & Parsing Safeguards**:
   - Handle `bytes` inputs safely by decoding with UTF-8 (`errors="replace"`).
   - Strip UTF-8 BOM (`\ufeff`) prefixes.
   - Use `json.loads(cleaned, strict=False)` to tolerate unescaped control characters (e.g. raw newlines/tabs inside string values generated by LLMs).
2. **Error Logging**:
   - Log `json.JSONDecodeError` at `logger.error` level when parsing fails.
   - Include the exception details (`line X column Y (char Z)`).
   - Include the `cleaned` text actually passed into `json.loads()`, ensuring character/line offsets correspond directly to the logged string.
   - Include the full raw response `content` if `cleaned` differs from `content`.
3. **Contract Preservation**:
   - Re-raise `ValueError(f"AI did not return valid JSON: {exc}\nResponse: {content[:500]}") from exc` as before.
4. **Testing**:
   - Update pytest unit tests to cover log output, `bytes` inputs, UTF-8 BOM handling, and unescaped control character tolerance.

## Detailed Design

### 1. `_parse_response` in `src/exif_tagger/ai_client.py`

Update `_parse_response(content: str | bytes)`:

```python
def _parse_response(content: str | bytes) -> TaggingResponse:
    """Parse the AI's response string into a structured TaggingResponse."""
    if isinstance(content, bytes):
        content = content.decode("utf-8", errors="replace")

    cleaned = content.strip().lstrip("\ufeff")

    # Try to extract JSON from markdown code blocks if present
    if "```" in cleaned:
        lines = cleaned.split("\n")
        json_lines = [l for l in lines[1:] if not l.startswith("```")]  # type: ignore[str-bytes-safe]
        cleaned = "\n".join(json_lines)

    # Strip any text outside the JSON object (keep first '{' to last '}')
    brace_start = cleaned.find("{")
    brace_end = cleaned.rfind("}")
    if brace_start != -1 and brace_end != -1 and brace_end > brace_start:
        cleaned = cleaned[brace_start : brace_end + 1]

    try:
        parsed = json.loads(cleaned, strict=False)
    except json.JSONDecodeError as exc:
        if cleaned != content:
            logger.error(
                "Failed to parse JSON response: %s\nText passed to json.loads:\n%s\nRaw response:\n%s",
                exc,
                cleaned,
                content,
            )
        else:
            logger.error(
                "Failed to parse JSON response: %s\nText passed to json.loads:\n%s",
                exc,
                cleaned,
            )
        raise ValueError(f"AI did not return valid JSON: {exc}\nResponse: {content[:500]}") from exc
```
